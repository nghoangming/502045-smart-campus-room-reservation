# Phân quyền RBAC

Hệ thống có ba vai trò: ADMIN, TEACHER và STUDENT. Mỗi tài khoản được gán vai trò qua bảng `user_roles`, mỗi vai trò gắn với tập quyền qua `role_permissions`.

![Hình 1. Phân quyền RBAC](../images/09_rbac.png)

*Hình 1. Phân quyền theo vai trò: ADMIN 17 quyền, TEACHER 11 quyền, STUDENT 6 quyền.*
